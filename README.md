# C++ Console Snake Game

A simple, classic Snake game built in C++ that runs directly in the Windows command prompt. The game features a colored ASCII interface and smooth, real-time input handling.

## Features
* **Classic Gameplay:** Eat the fruit to grow your snake and increase your score. Avoid hitting the walls or your own tail!
* **Colored Console Output:** Uses ANSI escape codes to make the game visually clear (Yellow Snake, Red Fruit, Blue Background).
* **Real-time Controls:** Uses non-blocking input so the snake moves continuously.

## Prerequisites
* **OS:** Windows (The game uses `<windows.h>` and `<conio.h>` for console manipulation and input).
* **Compiler:** Any standard C++ compiler (e.g., GCC/MinGW, MSVC) that supports C++11 or higher.

## Controls
* **Up Arrow:** Move Up
* **Down Arrow:** Move Down
* **Left Arrow:** Move Left
* **Right Arrow:** Move Right
* **Q / q:** Quit the game
